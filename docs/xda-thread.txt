[SIZE=5][B]About[/B][/SIZE]
A non-GKI 4.14 kernel for the Galaxy A32 4G with root and hiding built in:
[LIST]
[*][B]Aigis kernel[/B] by SlamZDank: Valhall GPU with its drivers module, Aigis' own CPU/GPU tuning
[*][B]BakaSU[/B] (KernelSU fork for non-GKI kernels), SUSFS inline hooks
[*][B]SUSFS v2.4.0[/B] by simonpunk, 4.14 port by JackA1ltman, all features on
[*][B]NoMount[/B] by maxsteeel, installed by the kernel ZIP (or built in)
[*]Network fix (UDP GSO), no LTO
[/LIST]
[B]Why BakaSU now?[/B] Until 22 Nov 2026 this kernel used xxKSU (backslashxx). Its developer archived xxKSU on 22 Nov 2026 (as of 23 Nov 2026 its future is unknown), so it gets no more fixes. I switched to BakaSU, which is actively developed. The Alt. kernel (mzggr) was xxKSU-only and is not developed anymore, so it is dropped. Old xxKSU builds stay on the releases page.
Tested on: SM-A325F, LumiROM 9 (Android 17). Other A325 models and ROMs should work but are not tested by me.

[B]This kernel and its whole build pipeline were made with the help of Perplexity Computer.[/B] Every build runs on GitHub Actions from public sources, so anyone can check and rebuild it.

Each release has: the kernel ZIP, the matching NoMount module ZIP (already inside the kernel ZIP too), and the BakaSU manager app ([ICODE]BakaSU_...apk[/ICODE]).

[SIZE=5][B]Installation[/B][/SIZE]
[LIST=1]
[*]Unlocked bootloader and TWRP or OrangeFox are required.
[*][B]Back up your current boot partition[/B] in recovery (Backup > Boot). This is your way back.
[*]Flash the kernel ZIP ([ICODE]A325X-Aigis-BakaSU-SUSFS-...zip[/ICODE]) in recovery. It also installs the matching NoMount module.
[*]Reboot and install the BakaSU manager app from the same release.
[*]Coming from my xxKSU kernel: uninstall the old xxKSU manager app, then check your modules and root apps in the BakaSU manager.
[/LIST]
Bootloop? Go back to recovery and restore the boot backup (or flash your stock boot.img).

[SIZE=5][B]FAQ[/B][/SIZE]
[B]Where is xxKSU / the mzggr kernel?[/B]
xxKSU was archived by its developer on 22 Nov 2026, so I stopped building it, and the mzggr kernel needed xxKSU. The last xxKSU builds (up to build-20261122-98) stay on the releases page, but they get no more updates.

[B]What is the -vgpu / -valhall ZIP?[/B]
The kernel with the Valhall GPU (default). It also installs the Valhall GPU drivers module, so no extra step is needed.

[B]Do I need the NoMount module?[/B]
Recommended, and the kernel ZIP already installs it. If you flash the separate NoMount ZIP, use the one from the same release.

[B]Can I use other KernelSU managers (official, Next, SukiSU, xxKSU)?[/B]
No, use the BakaSU manager from the release. Other managers do not match this kernel.

[B]Which SUSFS module should I use?[/B]
[B]BRENE is always recommended[/B] as the SUSFS userspace module: [URL='https://github.com/rrr333nnn333/BRENE']rrr333nnn333/BRENE[/URL]. It always keeps up to date with simonpunk's SUSFS updates, so it matches the SUSFS v2.4.0 in this kernel.

[COLOR=rgb(226, 80, 65)][B]Warning: do NOT use sidex15's susfs4ksu-module[/B][/COLOR] ([ICODE]SUSFS-FOR-KERNELSU[/ICODE]). It is not made for this kernel's SUSFS version and can break root hiding or cause problems. If it is installed, remove it in the BakaSU manager, reboot, then install BRENE.

[B]Release or pre-release?[/B]
Releases are tested by me on my phone. Pre-releases are built automatically when an upstream source changes and are not tested yet.

[LIST=1]
[*]Download [URL='https://raw.githubusercontent.com/Najip/KernelSU_SUSFS_Samsung_SM-A325X/main/tools/collect-logs.sh']collect-logs.sh[/URL] to [ICODE]/sdcard/Download/[/ICODE].
[*]After a bootloop, go straight to recovery (do not power off), so the crash log is still in memory.
[*]TWRP: Advanced > Terminal, run [ICODE]sh /sdcard/Download/collect-logs.sh[/ICODE]

[B]Build problems (if you build it yourself):[/B] save the raw job log and run [URL='https://github.com/Najip/KernelSU_SUSFS_Samsung_SM-A325X/blob/main/tools/extract_log.py']extract_log.py[/URL] on it, then attach the [ICODE]-important.txt[/ICODE] it makes.
