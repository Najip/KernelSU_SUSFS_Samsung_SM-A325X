[SIZE=5][B]About[/B][/SIZE]
A non-GKI 4.14 kernel for the Galaxy A32 4G with root and hiding built in:
[LIST]
[*][B]xxKSU[/B] (KernelSU fork by backslashxx for non-GKI kernels), manual hooks
[*][B]SUSFS v2.4.0[/B] by simonpunk, 4.14 port by JackA1ltman, all features on
[*][B]NoMount[/B] by maxsteeel, as a matching module (or built in)
[*]Network fix (UDP GSO), no LTO
[/LIST]
Two kernels are released, flash only one:
[LIST]
[*][B]Main kernel: Aigis[/B] (by SlamZDank). The one I use every day. Valhall GPU with its drivers module, Aigis' own CPU/GPU tuning.
[*][B]Alt. kernel: mzggr[/B] (by mzggr0914). Stock A32 GPU, with my performance tuning (GPU 1100 MHz, undervolt, BORE, 250 Hz, schedutil, BBR).
[/LIST]
Tested on: SM-A325F, LumiROM 9 (Android 17). Other A325 models and ROMs should work but are not tested by me.

[B]This kernel and its whole build pipeline were made with the help of Perplexity Computer.[/B] Every build runs on GitHub Actions from public sources, so anyone can check and rebuild it.

[SIZE=5][B]Installation[/B][/SIZE]
[LIST=1]
[*]Unlocked bootloader and TWRP or OrangeFox are required.
[*][B]Back up your current boot partition[/B] in recovery (Backup > Boot). This is your way back.
[*]Flash ONE kernel ZIP ([ICODE]A325X-Aigis-...zip[/ICODE] or [ICODE]A325X-mzggr-...zip[/ICODE]) in recovery.
[*]Reboot and install the xxKSU manager app from the same release.
[*]In the manager, flash the NoMount ZIP made for the same kernel ([ICODE]...-aigis-...[/ICODE] or [ICODE]...-mzggr-...[/ICODE]) as a module, then reboot.
[/LIST]
Bootloop? Go back to recovery and restore the boot backup (or flash your stock boot.img).

[SIZE=5][B]FAQ[/B][/SIZE]
[B]Which kernel should I pick?[/B]
Aigis if you want the Valhall GPU and the kernel I use daily. mzggr if you want the stock GPU with extra tuning. If mzggr freezes or reboots under load, your phone may not like the undervolt; use Aigis.

[B]What is the -vgpu / -valhall ZIP?[/B]
The Aigis kernel with the Valhall GPU. It also installs the Valhall GPU drivers module, so no extra step is needed.

[B]Do I need the NoMount module?[/B]
Recommended. Always use the NoMount ZIP from the same release and for the same kernel. The kernel ZIP warns you if the installed one does not match.

[B]Can I use other KernelSU managers (official, Next, SukiSU, BakaSU)?[/B]
No, use the xxKSU manager from the release. Other managers do not match this kernel.

[B]Which SUSFS module should I use?[/B]
Any module made for SUSFS v2.4.0 (for example BRENE). Older modules for SUSFS 1.5.x do not work.

[B]Release or pre-release?[/B]
Releases are tested by me on my phone. Pre-releases are built automatically when an upstream source changes and are not tested yet.
